Spell Fencer · animations + auras

Keren's class (Spellblade Rhapsody SL 1, Spellweave SL 2). Rules approved on the class page (rounds 1-4); this round is the look only.

What is on this page

  1. Spellblade RhapsodyThe activation, self only: guard stance, red and blue ribbons braid up (pixelfx), flash + notes + the game's buff beat where they meet, then the braid aura holds. About 2.2 s at the default speed.
  2. +1 ResonanceThe pulse a switch plays when it grants a stack: gold ring at the chest, one pixel note, a soft chime. About 0.8 s.
  3. Four held aurasNext Spell (blue), Next Attack (red), Resonance ready (gold, 2+ stacks) and Rhapsody Turn (braid). They are token status cues in the game, so each is a loop you can approve and tune here like a move.
  4. The sandboxUnder the move sheet: Attack / Offensive Spell / Rhapsody / End turn switch the auras the way the game will, and play the pulse and the activation when they happen.

How it ships

  1. The two moves run as writtentools/move-engine/moves/spell-fencer/head.js + rhapsody.js are the files the game builds: Rhapsody goes into the Spellblade Rhapsody item's animation_script; the pulse plays from a play_animation row on Spellweave's gain rows.
  2. The auras are status cuesSame technique and scale as Burn, Poison and Berserk (status-cues.js: a layer docked to the drawn sprite, particles sized by sprite height). The page's cue code is the port source: copy its CSS + HTML blocks, map the marker AEs to the cue ids.
  3. Hidden during actionsLike every status cue, the auras fade out while an action animation plays and come back after it.

Real assets vs stand-ins

  1. The game's own lookValley_Battlemap001 on the 3D stage, the party line at in-game battler size and depth, Keren's token art (Keren_Standard), RPG Maker MV 051_powerup_1 + Powerup.ogg (the game's buff beat), Forge Soundboard sounds.
  2. New artThe ribbon braid is a new pixelfx effect (fu/spellblade-braid), exported soft ×2 in three layers like the other pixelfx clips. Its webms are not on Forge yet.
  3. Not shownThe action card (namecard) and the Resonance count on the HUD plate: the game draws those itself.

How to review

  1. Play each entryThe two moves and the four auras each have a review card: approve, ask for changes or reject, write a note.
  2. Pause & comment (C)Pins the exact moment; Space pauses and resumes.
  3. TuneEvery number is a slider. The braid's radius, note count and colours are baked into the clip, so they are selects between pre-made versions.
  4. Send feedbackOne button in the side panel.
